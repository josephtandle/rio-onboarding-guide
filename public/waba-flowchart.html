🌊 Rio WABA Setup — Complete Flow

Updated 2026-03-24 · Every path, every error, every decision — from start to connected

START: Begin Rio WABA Setup
Go to Rio dashboard → "Connect WhatsApp"
Q1: Are you migrating from another provider?
ManyChat, Wati, 360dialog, or any other WhatsApp API provider
PATH D — Migration
Migrating from another WhatsApp API provider. Steps TBD.
Q2: Which option will you choose in the signup?
After selecting your Business Portfolio, choose the WhatsApp account type
⚠ RESEARCH — Mark
When to use each WBA option?
"Connect a WhatsApp Business App" = already have WBA running on phone. Exact conditions for "Create" TBD.
PATH B — Create a WBA
Create a WhatsApp Business account for a new or existing number
PATH C — Connect WBA App
Connect a WhatsApp Business App already running on your phone
B1
Open Rio's Setup Link
Log in to Rio → "Connect WhatsApp" → Facebook popup opens. Log in with Facebook.
B2
Select Business Portfolio
Pick existing portfolio or create a new one in the dropdown.
B3
Select "Create a WhatsApp Business account"
Choose this option in the WhatsApp Business account dropdown.
B4
Enter Business Information
Name, category, website, timezone. Name must match website.
B5
Choose "Add a new number"
Always select this. "Use display name only" does not give customers a real number to reach you.
B6
Enter Phone Number + Display Name
Country code + number. Display name must match company name exactly — no emojis or trademark symbols. Choose SMS or Phone call to verify.
B6.I — DEAD END
⛔ Number already registered to WhatsApp
"This phone number is already registered to a WhatsApp account."
B6.I Fix
Delete number from WhatsApp app first
WhatsApp → Settings → Account → Delete account. Wait 3 min, then retry. (Full fix instructions coming.)
B7
Enter Verification Code
Check your phone for the 6-digit code. Enter it and click Verify.
B8 ✓
Connected!
WhatsApp Business number is now live on Rio. Display name review may take minutes to days.
C1
Enter WhatsApp Business Phone Number
Enter the number currently running on your WhatsApp Business App. If not yet in your portfolio, Meta will ask you to verify it.
C1.I — DEAD END
⛔ Number limit reached
"You'll need to delete an existing one from WhatsApp Manager or request additional numbers."
C1.I Fix
Remove WBA from Business Portfolio
business.facebook.com → Accounts → WhatsApp accounts → ⋯ → Remove from business portfolio. Wait 3 min–24h.
C1.II — DEAD END
⛔ Already sharing with a partner
"The business is already sharing this WBA with a partner. Switching partners is not supported in this flow."
C1.II Fix
Remove WBA from Business Portfolio
Same fix as C1.I — business.facebook.com → Accounts → WhatsApp accounts → ⋯ → Remove from business portfolio. Wait 3 min–24h.
C1.I / C1.II — Permission Sub-fix
⚠️ If you get a permission error when removing:
Click Assign People → select yourself → Full control: Everything → Assign. Then retry removal.
C2
Confirm Permissions
Review what Rio is requesting access to. Click Continue or Allow.
C3 ✓
Connected!
WhatsApp Business App number is now live on Rio.
